# AD Project Candidate–Job Matcher: v4

## Intended use

`match-hgb-retrieval-v4` ranks jobs for a candidate and candidates for a job. It is an advisory
retrieval and ranking component. It must not automatically accept, reject, shortlist, or change an
application status.

## Model and features

- Algorithm: monotonic `HistGradientBoostingRegressor` from scikit-learn.
- Model version: `match-hgb-retrieval-v4`.
- Feature version: `pair-features-v1+prelabel-features-v3`.
- Training pairs: 738,900 across 2,463 Candidate query groups.
- Labels: AI teacher expected relevance plus conservative hard-negative corrections.
- Hard-negative corrections: 238,009 pairs (32.2113%).

v4 adds job-data quality filters, technical-context handling for ambiguous skills such as React,
desired-title features, software subdomains, monotonic constraints, and score caps for explicit
zero-skill/title mismatches.

## Evaluation

Group-held-out teacher-agreement validation:

| Metric | v4 |
|---|---:|
| MAP@10 | 0.967368 |
| Eligible-query MAP@10 | 0.977280 |
| NDCG@10 | 0.976094 |
| Precision@5 | 0.956592 |
| Recall@10 | 0.261589 |

The separate 20-query frozen teacher audit has MAP@10 0.991667 and zero query overlap with
training. These are teacher-agreement measurements, not real hiring accuracy or human blind-test
results.

The deterministic counterfactual suite requires Backend candidates to rank Backend above React,
Frontend candidates to rank React above Backend, matching skills not to reduce scores, and explicit
zero-skill/title mismatches to score no more than 45.

## Limitations and risks

- Most labels are generated by an AI teacher and can preserve teacher bias.
- The source job dataset contains noisy text and has no explicit redistribution license.
- Exact skill matching can under-value transferable skills and synonyms.
- A 0–100 score is a match score, not a probability of interview or employment.
- Demographic and protected attributes are neither intended inputs nor acceptable ranking signals.
- Human review and a genuinely independently labeled blind set are still required before any
  production hiring use.

## Reproducibility and safety

Use Python 3.12 and the exact dependencies in `environment.yml`. Only load `joblib` artifacts from
trusted sources because loading a malicious pickle/joblib file can execute code. Verify the model
version and dataset hash in `artifacts/active/manifest.json` before serving it.
